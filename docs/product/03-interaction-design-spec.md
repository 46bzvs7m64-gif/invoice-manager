# 发票管家 · 用户交互设计规范

> 版本：v1.0（MVP）  |  日期：2026-09-21

---

## 一、设计原则

### 1.1 核心体验目标
- **高效**：3 步内完成"查发票→标记使用"的核心操作
- **清晰**：状态一目了然，未使用/已使用视觉区分明确
- **稳定**：采集、识别过程有明确进度反馈，不让用户"猜"
- **容错**：识别结果可编辑，操作可撤销

### 1.2 视觉风格
| 维度 | 规范 |
|---|---|
| 主色调 | 蓝色系 `#2563EB`（专业、可信） |
| 辅助色 | 成功 `#16A34A`、警告 `#F59E0B`、错误 `#DC2626` |
| 背景色 | 浅灰 `#F8FAFC`，卡片白色 `#FFFFFF` |
| 字体 | 系统默认无衬线，正文 14px，标题 16-20px |
| 圆角 | 卡片 8px，按钮 6px，标签 4px |
| 间距 | 页面内边距 16px（移动端）/ 24px（PC），卡片间距 16px |

### 1.3 响应式断点
| 设备 | 宽度 | 布局 |
|---|---|---|
| 手机 | < 768px | 单列，底部导航栏 |
| 平板/小屏 PC | 768px - 1024px | 单列或双列 |
| PC | ≥ 1024px | 左侧固定导航 + 右侧内容区 |

## 三、页面详细设计

### 3.1 仪表盘（首页）

**页面目标**：一眼掌握发票整体情况，快速进入核心操作

**布局**：
```
┌─────────────────────────────────────┐
│  顶部：标题「发票管家」 + 一键采集按钮  │
├─────────────────────────────────────┤
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ │
│  │ 总数  │ │总金额 │ │未使用 │ │未使用 │ │
│  │ 128  │ │¥35,680│ │ 45   │ │¥12,300│ │
│  └──────┘ └──────┘ └──────┘ └──────┘ │
├─────────────────────────────────────┤
│  月度发票金额趋势（折线图）            │
├─────────────────────────────────────┤
│  销售方 TOP 5（横向条形图）            │
├─────────────────────────────────────┤
│  最近采集的发票（列表，最近 5 条）      │
└─────────────────────────────────────┘
```

**交互**：
- 点击「一键采集」→ 跳转采集页或弹出采集进度
- 点击数据卡片 → 跳转对应筛选的发票列表
- 月度趋势图可点击某月 → 跳转该月发票列表
- 销售方排行可点击 → 跳转该销售方的发票列表

**移动端适配**：
- 数据卡片改为 2×2 网格
- 图表高度压缩，支持横向滚动

## 四、核心操作流程

### 4.1 首次使用流程
```
启动应用
  ↓
配置邮箱（填写地址+授权码，测试连接）
  ↓
配置大模型 API Key
  ↓
一键采集（等待扫描+下载+识别完成）
  ↓
查看入库结果
  ↓
进入发票列表/归类视图浏览
```

### 4.2 日常使用流程（查询并标记发票）
```
打开发票列表
  ↓
设置筛选条件（销售方/日期/金额）
  ↓
浏览结果，点击目标发票
  ↓
查看详情和预览
  ↓
确认后点击「标记已使用」
  ↓
（可选）填写使用备注
  ↓
状态变为已使用，默认列表不再显示
```

### 4.3 采集异常处理流程
```
一键采集
  ↓
部分发票识别失败
  ↓
列表中显示「识别失败」标签
  ↓
点击该发票 → 查看失败原因
  ↓
手动编辑字段 或 点击「重试识别」
```

## 五、组件规范

### 5.1 状态标签
| 状态 | 样式 |
|---|---|
| 未使用 | 蓝色背景 `#DBEAFE` + 蓝色文字 `#1D4ED8`，圆角 4px，内边距 2px 8px |
| 已使用 | 灰色背景 `#F1F5F9` + 灰色文字 `#64748B`，文字带删除线 |
| 识别失败 | 红色背景 `#FEE2E2` + 红色文字 `#B91C1C` |

### 5.2 按钮
| 类型 | 样式 | 场景 |
|---|---|---|
| 主按钮 | 蓝色背景 `#2563EB` + 白色文字 | 一键采集、标记已使用、保存 |
| 次按钮 | 白色背景 + 灰色边框 | 取消、重置、下载 |
| 危险按钮 | 红色背景 `#DC2626` + 白色文字 | 删除、清空 |
| 文字按钮 | 无背景 + 蓝色文字 | 编辑、重试、查看详情 |

### 5.3 空状态
- 无发票时：显示插画 + 「还没有发票，点击一键采集开始」
- 筛选无结果时：显示「没有符合条件的发票」+ 重置筛选按钮
- 采集无新发票时：显示「本次未发现新发票」

## 六、移动端专项规范

### 6.1 导航方式
- 底部固定导航栏，4 个 Tab：首页、发票、归类、我的
- 顶部标题栏 + 返回按钮

### 6.2 操作手势
- 列表项左滑：显示「标记使用」「删除」快捷操作
- 下拉刷新：刷新当前列表
- 长按列表项：进入多选模式

### 6.3 键盘适配
- 表单输入时，避免输入框被键盘遮挡
- 日期选择、下拉选择使用原生组件

## 七、错误提示规范

| 场景 | 提示方式 | 文案示例 |
|---|---|---|
| 邮箱连接失败 | Toast + 红色提示 | 「连接失败：授权码错误，请检查」 |
| 网络异常 | Toast | 「网络异常，请检查连接后重试」 |
| 采集完成 | 弹窗 + 统计 | 「采集完成：扫描 100 封邮件，入库 12 张发票」 |
| 识别失败 | 列表标签 + 详情提示 | 「识别失败：[原因]，可重试或手动编辑」 |
| 标记成功 | Toast | 「已标记为已使用」 |
| 删除确认 | 确认弹窗 | 「确定删除这张发票吗？文件也将被删除」 |
