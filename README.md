# 发票管家 · 完整版（采集 · 识别 · 归类检索 · 仪表盘）

自动从 QQ/163 邮箱采集电子发票附件，过滤非发票邮件，去重入库，调用通义千问大模型自动识别发票字段（发票号、日期、金额、销售方等），并支持按开票对象归类、多条件检索、"标记已使用"、仪表盘统计与报销单导出，形成发票管理完整闭环。

## 已完成功能（阶段一 ~ 四，全部完成）

- 邮箱配置：QQ / 163 邮箱一键填充，授权码加密存储，连接测试
- 一键采集：增量同步（只拉新邮件）、三层过滤（服务端日期 → 主题/发件人 → 文件魔数/黑名单）、MD5 去重
- 手动上传：在「发票采集」页拖拽或点选上传本地 PDF/OFD 发票，支持多文件，同样经过格式/魔数校验与 MD5 去重（适合从平台手动下载的发票）
- 智能识别：本地 PDF 以 Base64 直传百炼 OpenAI 兼容接口，调用 qwen3.8 模型，按固定 JSON 结构提取并自动归一化（日期 YYYY-MM-DD、金额去符号去千分位），发票号自动去重
- 批量识别：支持「待识别 / 识别失败 / 全部重识别」三种范围，实时进度与日志
- 异常兜底：识别失败记录原因，可单张重试；OFD 不支持自动识别，可手动录入
- 归类视图：按销售方 / 购买方折叠分组，组级显示张数、金额合计、日期跨度，展开可见组内发票
- 多条件检索：销售方、购买方、开票日期范围、金额区间、发票类型、消费类目、关键词，任意组合；支持按日期/金额升降序；实时显示结果金额合计
- 标记使用：单张标记/撤销、勾选后批量标记，可填写使用备注（如报销单号）；已使用发票默认不出现在结果中，可筛选查看历史
- 仪表盘：发票总数/总金额、未使用数量/金额，近 6 个月金额趋势图，开票对象 TOP5 排行，最近采集列表
- 报销单导出：按当前筛选条件导出 Excel（含合计行），可选"导出并标记已使用"一键完成报销闭环

## 快速开始

1. 安装 Python 3.10+（安装时勾选 "Add Python to PATH"）

2. 安装依赖并启动：

```powershell
cd d:\简历模板\invoice-manager\backend
pip install -r requirements.txt
python run.py
```

3. 打开浏览器访问：<http://127.0.0.1:8000>

4. 手机访问（同一 WiFi）：手机浏览器打开 `http://<电脑局域网IP>:8000`
   - 查看电脑 IP：`ipconfig` 中的 IPv4 地址（如 192.168.1.100）

## 邮箱授权码获取方式

**QQ 邮箱：**
1. 登录网页版 → 设置 → 账号
2. 找到「POP3/IMAP/SMTP 服务」，开启「IMAP/SMTP 服务」
3. 按提示用手机发送短信验证，获得 16 位授权码

**163 邮箱：**
1. 登录网页版 → 设置 → POP3/SMTP/IMAP
2. 开启「IMAP/SMTP 服务」
3. 弹出的授权码窗口中点击「新增授权密码」，获得授权码

## 使用流程

1. 配置 API Key：编辑 `backend/.env`，将百炼 API Key 填到 `QWEN_API_KEY=` 后面并保存
2. 「邮箱配置」页：点快速填充 → 填邮箱地址和授权码 → 测试连接 → 保存
3. 「发票采集」页：设置天数（默认 90 天）→ 点「一键采集」→ 观察实时日志；本地已有的发票可在同页「手动上传发票」区拖拽上传（PDF/OFD，可多选）
4. 「智能识别」页：选择范围（默认"待识别"）→ 点「开始识别」
5. 「仪表盘」页：掌握总量、金额、趋势与对象排行
6. 「归类视图」页：按销售方/购买方浏览分组，点击对象展开组内发票
7. 「发票列表」页：按对象/日期/金额等条件检索；确认使用后点「标记」或勾选后「批量标记已使用」；点「导出报销单」可按当前筛选导出 Excel（可选同时标记已使用）

## 识别相关说明

| 项 | 说明 |
|---|---|
| 获取 API Key | 访问 https://bailian.console.aliyun.com → 开通百炼服务 → 创建 API Key |
| 默认模型 | `qwen3.8-flash`（低成本）；在 `.env` 中改为 `QWEN_MODEL=qwen3.8-max` 可获得更高精度 |
| 接口地址 | 默认华北2北京 `https://dashscope.aliyuncs.com/compatible-mode/v1`；海外可用 `QWEN_BASE_URL` 切换 |
| 提取字段 | 发票号码、类型、开票日期、价税合计、不含税金额、税额、销售方/购买方名称及税号、消费类目 |
| 计费 | 按模型输入/输出 Token 计费，单张发票通常几分钱以内；以百炼控制台价格为准 |
| OFD 发票 | 暂不支持自动识别，请到「发票列表」点「编辑」手动录入 |

## 过滤规则说明

| 层级 | 规则 |
|---|---|
| 服务端 | IMAP SEARCH：仅最近 N 天（默认 90），仅收件箱 |
| 客户端 | 主题含「发票/invoice」或发件人域名在白名单中才视为候选 |
| 文件级 | 仅 .pdf/.ofd；PDF 魔数校验（%PDF-）；文件名/主题命中黑名单（结账单/对账单/行程单/账单等）跳过；MD5 相同去重 |

## 常见问题

- **登录失败 / 授权码错误**：确认使用的是 16 位授权码而非邮箱登录密码；确认 IMAP 服务已开启
- **163 邮箱报 Unsafe Login**：程序已自动发送 IMAP ID 命令处理，若仍失败请重启程序重试
- **手机访问不了**：检查电脑防火墙是否放行 8000 端口；确认手机与电脑在同一 WiFi
- **重复采集会重复入库吗**：不会。已处理邮件通过 UID 游标跳过；相同文件通过 MD5 去重
